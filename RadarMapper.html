Initialisation

Charge une image de radar, lance une détection locale par canvas, puis enrichis les zones avec le LLM configuré si l’usage est autorisé.

Fonctionnalités en cours : la détection automatique, l'OCR et le mapping IA ne sont pas encore pleinement fonctionnels dans cette version.

Le JSON initial contient maintenant des exemples et des consignes pour aider un LLM à restituer le bon format.

Importe un JSON initialisé ou un JSON enrichi, ajuste les zones avec l’éditeur, puis exporte le JSON ou le HTML autonome cliquable.

Raccourcis : flèches pour déplacer, Maj+flèches pour 10 px, Suppr pour supprimer. L’export génère un fichier HTML autonome avec l’image intégrée.

Popup

Pour Wavestone Insights et RiskInsight, le plus robuste est d'héberger la page autonome puis d'intégrer le snippet iframe. Si le CMS autorise les blocs HTML avec script, le snippet CMS évite l'iframe. Si le script est filtré, l'image map garde les liens essentiels.

Configuration

Aucune clé API n’est nécessaire pour l’édition manuelle. La clé API n’est jamais sauvegardée : elle reste uniquement dans le champ courant et doit être ressaisie après rechargement.
Confidentialité

Pour des raisons de confidentialité, l’usage d’un fournisseur d’IA doit être explicitement approuvé par l’organisation concernée.
